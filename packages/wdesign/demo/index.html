08 · 文档排版

MARKDOWN 样式

.wd-markdown 包裹渲染后的 HTML；引用块嵌套为静态分层，父级不会被连带高亮。

项目说明文档

这是一个 Markdown 渲染示例，覆盖标题、列表、链接、行内代码、表格与引用等常用排版。加粗与斜体同样适用，快捷键 ⌘ K。

引用块（嵌套是静态分层）

一级引用：浅红底 + 左侧色条。

二级引用：白卡浮出，父级不受影响。

三级引用：再加深一档。修复前 hover 任意一层会点亮全部父级，现在没有这个问题。

列表

  • 无序项：设计令牌全部走 var(--wd-*)
  • 嵌套：
    • 间距 4pt 基准
    • 圆角 12–32
  1. 引入样式 wdesign/src/styles/index.scss
  2. 容器加类名 .wd-markdown
