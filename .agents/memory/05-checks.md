# 05 · 检查器

## 为什么需要

这几轮修的 bug **全是「静默失效」**：

| 症状 | 根因 |
|---|---|
| 图标渲染空白 | 图标名拼错，不报错 |
| 样式不生效 | CSS 变量不存在，声明被丢弃 |
| 元素永不显示 | 动画时钟停摆 |
| 宽度异常 | `duration: Infinity` → `width: NaN%` |
| 元素永不显示 | `v-show` 覆盖 `display` |
| 监听失效 | 事件名不匹配 |
| 产物缺模块 | 构建路径错 |

**每一个都是靠肉眼发现的。这类问题只能在工具层面拦。**

## 现有检查项（`tools/smoke-test.mjs`）

| # | 检查 |
|---|---|
| 1 | 每个组件能通过 SFC 编译器（抓语法/模板错误） |
| 2 | 组件都声明了 `defineOptions.name` |
| 3 | props/emits 里没有 camelCase 事件名 |
| 4 | 没有手写 `<svg>`（必须走 WdIcon） |
| 5 | 浮层组件的面板必须有 Teleport |
| 6 | 用 `<Transition>` 的地方必须有 `:duration` 兜底 |
| 7 | 引用的 CSS 变量和图标名都存在 |
| 8 | 构建产物完整 |
| 10 | 模板用到的 BEM 类名，样式表里必须有定义 |
| 11 | 组件模板不该串用其它组件的 BEM 块 |
| 13 | 组合式 API 必须已 import |
| 14 | 定位元素不得用 `transform: scale` 做尺寸变化 |
| 16 | 图标包必须有独立的样式出口 |
| 17 | `box-sizing` 的全局声明唯一性（且必须包含伪元素） |

## 运行

```sh
cd packages/wdesign-ui
npm run verify        # check:tokens + check:icons + typecheck + smoke-test
```

## ⚠️ 不许放水（最重要的一条）

**修完检查器后，必须注入一个已知错误验证它仍然会失败。**

```sh
# 例：验证图标名检查
# 注入一个不存在的图标名，确认检查仍然失败
```

否则等于把刹车拆了——检查显示"全部通过"，但实际什么都抓不到。

> 这条写在 CONVENTIONS 第 23 条。曾经有过"修完检查器反而不再报错"的事故。

## 检查器的两个设计取舍

### 类名检查用「字符串包含」而非解析 SCSS 嵌套

前一版试图按 `{}` 维护嵌套栈来展开 `&__el`，但 SCSS 里有
`@media` / `@include` / 逗号多选择器 / 单行写法，逐行判断层级极其脆弱，
误报了几十个"未定义"。

改成最朴素的方式：只要类名或它的基名在样式源码里出现过就算定义。
这能可靠抓住"整组类名从未写过"（Modal 事故），又不会误报。

### 令牌检查器要跳过注释

它逐行扫 `var(--wd-*)`，不区分注释 ——
在注释里举例写 `var(--wd-xxx)` 会被当成真实引用，每次都被误报。

**修法**：扫描前剥离 `/* */` 与 `//` 注释（用换行占位保持行号不变）。
