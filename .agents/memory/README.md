# WDesign 开发约束记忆

> 本目录是**长期生效的开发约束**，与具体机器环境无关。
> 包含踩坑清单、架构决策、禁止事项。改动代码前先读对应文件。

## 阅读顺序

| 文件 | 内容 | 何时读 |
|---|---|---|
| `01-architecture.md` | 仓库结构、包职责、构建链路 | 动结构 / 加包 / 改构建时 |
| `02-style-rules.md` | SCSS 与 SFC 写法硬规则 | 写组件 / 改样式时 |
| `03-pitfalls.md` | 27 条踩坑清单（防复发） | 遇到怪问题先查这里 |
| `04-release.md` | 发布流程与验证策略 | 发版时 |

| `06-workflow.md` | 开发流程与协作约定 | 日常开发 |

## 三条最高优先级

1. **不许静默失效**。任何"看起来生效了其实没生效"的写法都要改掉：
   `var()` 的 fallback、`transition` 承载状态、`:deep()` 写在全局 SCSS、
   esbuild 的默认 tree-shaking 删库导出。这些都是**不报错但不工作**。

2. **检查器不许放水**。修检查器时，必须注入一个已知错误验证它仍然会失败。
   否则等于把刹车拆了。

3. **禁止重启任何服务或主机**。配置改动只改文件，重启动作交给用户。
   （曾因重启 w-yun 的 wtunnel 打断了 SSH 穿透。）
